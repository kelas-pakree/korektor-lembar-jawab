# Kelas Pakree - Korektor Lembar Jawab Siswa

Aplikasi pengoreksi lembar jawab asesmen untuk guru Madrasah Ibtidaiyah. Satu berkas HTML yang berjalan di browser, bisa dipasang dan dipakai tanpa internet. Claude (claude.ai) dipakai lewat salin dan tempel.

- Data siswa dan hasil koreksi hanya tersimpan di browser perangkat masing-masing. Repositori ini tidak berisi data siswa.
- Pemasangan dan cara pakai: buka menu **Panduan** di dalam aplikasi.
- Memperbarui: timpa `index.html` dan `sw.js` dengan versi baru. Nomor versi di dalam `sw.js` harus ikut berubah agar perangkat mengenali pembaruan.
